# 台灣引水人考試歷屆題庫與備考平台

以高雄港為主要備考港區，整理全台引水人考試歷屆試題；共通科目依原卷適用考區整理，當地水道港灣詳情則保留港區差異。

## 目前題庫狀態

- 正式備考範圍：20 個考試年度（民國 83、84、85、86、87、89、90、91、92、94、96、98、100、102、104、106、108、110、112、114 年）。
- 正式範圍題目：604 題。
- 歷史備查：民國 82 年 12 題，不列入正式年度篩選與網站統計。
- 資料庫合計：616 題。
- 官方來源索引：108 份。
- 題目狀態：目前 616 題均標記為「已核對」；仍需進行第二輪逐題校對，特別注意早期掃描原卷的字形、數字、英文拼字、題分及公式。
- 題目 ID 無重複，且每題均有 sourceId 可對應來源索引。

詳細年度題數、科目分布及匯入紀錄請見 [docs/IMPORT_STATUS.md](docs/IMPORT_STATUS.md)。

## 專案原則

- 每道正式歷屆題目都記錄原始試卷或官方來源。
- 不把其他港區地方科目冒充高雄港題目。
- 跨港區共通科目統一整理；港灣／水道等港區專業內容另標示港區。
- 舊年度科目名稱依原卷保留，不強行改寫成現行科名。
- 年度以實際舉辦考試的官方資料為準，不自行推定未舉辦年度。
- 題目文字以官方原卷為依據；擬答與實務解析將另階段建立，不冒充官方答案。

## 擬答與實務解析資料架構

- 已建立 `data/answers.json` 作為獨立答案資料庫，並以 `questionId` 關聯題目；初始為空，不以未查證內容充數。
- `data/answer.schema.json` 定義答案欄位、來源引用、假設限制及查核狀態。
- `docs/ANSWER_AUTHORING.md` 規範各科證據來源優先序、操船情境分析步驟、法規／港規版本控管及上架門檻。
- 擬答與實務解析明確區分；除非有官方解答或評分標準來源，不稱為官方標準答案。

## 網站功能

- 依港區、年度、考科及關鍵字篩選題目。
- 每題提供考選部原卷 PDF 來源連結。
- 預設以高雄港作為主要港區。
