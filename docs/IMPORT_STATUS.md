# 歷屆考題匯入與查核紀錄

最後更新：2026-11-05

## 狀態定義
- 待取得：尚未取得可讀取的原始試卷。
- 已取得：已取得原始檔，但尚未逐題核對。
- 已核對：題目文字已對照原始試卷。
- 已匯入：已寫入題庫並可在網站顯示。

## 匯入規則
每份試卷登錄年度、考試類別／港區、科目、原始網址或檔案名稱、取得日期及備註。每道題目記錄唯一 ID、年度、科目、港區、題目全文、來源 ID、頁碼／題號及查核狀態。
