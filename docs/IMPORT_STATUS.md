## 狀態定義
- 待取得：尚未取得可讀取的原始試卷。
- 已取得：已取得原始檔，但尚未逐題核對。
- 已核對：題目文字已對照原始試卷。
- 已匯入：已寫入題庫並可在網站顯示。
