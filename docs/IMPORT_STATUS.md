# 歷屆考題匯入與查核紀錄

最後更新：2026-11-05

## 狀態定義
- 待取得：尚未取得可讀取的原始試卷。
- 已取得：已取得原始檔，但尚未逐題核對。
- 已核對：題目文字已對照考選部官方原始試卷。
- 已匯入：已寫入 data/questions.json，並可由網站題庫讀取。

## 目前成果
- 已建立公開 GitHub Repository、Next.js 題庫網站骨架、題目與來源資料檔。
- 題庫主港區：高雄港。
- 「當地水道港灣詳情」採高雄港試卷；航政法規、引港學、船舶操縱、專業英文採各港共通試卷。
- 已完成 12 個實際考試年度的五科官方試卷核對與匯入，共 60 份來源、314 題。
- 已匯入年份（民國）：92、94、96、98、100、102、104、106、108、110、112、114。
- 未舉辦考試的年份不建立空白年度；考試年份依實際官方考試紀錄判定。
- 題目文字以官方試卷為準；圖面題、繪圖題會保留題目要求，不自行臆造圖形答案。
