# 歷屆考題匯入與查核紀錄

最後更新：2026-11-05

## 狀態定義
- 待取得：尚未取得可讀取的原始試卷。
- 已取得：已取得原始檔，但尚未逐題核對。
- 已核對：題目文字已對照考選部官方原始試卷或官方原卷影像。
- 已匯入：已寫入 data/questions.json。

## 題庫範圍與資料規則
- 主要備考港區：高雄港。
- 五科：當地水道港灣詳情、航政法規、引港學、船舶操縱、專業英文。
- 當地水道港灣詳情依港區分開；其他四科依當年度官方試卷所適用的引水區共用。
- 90 年考試為第三次航海人員、引水人特考，該次甲種引水人考區為基隆港及和平港，並沒有高雄港當地水道科目。因此 90 年資料保留基隆港、和平港地方科目，四科共通科目則共用；不可把地方科目誤標成高雄港。
- 年度以實際考試紀錄為準，不因「大致兩年一次」而自行推定未舉辦年度。
