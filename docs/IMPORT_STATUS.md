## 狀態定義
- 待取得：尚未取得可讀取的原始試卷。
- 已取得：已取得原始檔，但尚未逐題核對。
- 已核對：題目文字已對照原始試卷。
- 已匯入：已寫入題庫並可在網站顯示。

目前已完成 25 份官方試卷的題目核對與匯入，共 129 題；另有 25 份較早年度官方來源已建立索引，但尚未逐題核對及匯入，並非完整歷屆題庫。未取得或尚未核對的科目、港區及年度，不得標示為已完成，也不得用猜測或自行編寫內容冒充歷屆考題。

## 匯入規則
每份試卷登錄年度、考試類別／港區、科目、官方原始網址或檔案名稱、頁數及查核備註。每道題目記錄唯一 ID、年度、科目、港區、題目全文、來源 ID、題號及查核狀態。
