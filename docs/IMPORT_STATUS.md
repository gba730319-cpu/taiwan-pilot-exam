## 題庫規則
- 主要備考港區：高雄港。
- 題庫保存已取得之其他港區原卷，不把其他港區地方科目冒充高雄港題目。
- 當地水道港灣詳情依港區區分；其他科目依官方原卷適用考區共用。
- 舊年度科目名稱依原卷保留，例如民國 85、86、87、89 年原卷的「實用英文」不改寫為「專業英文」。
- 年度以實際舉辦考試的官方資料為準，不因兩年一次的常態自行推定年度。
- 只匯入可追溯至考選部官方試卷或官方典藏影像的題目；原卷未取得的年度不補造題目。

- 考選部說明：92 年以前試題可由官方網站歷年試題查詢及圖書館公開陳列等方式查閱；92 年以後考畢試題於考試結束隔日上載。
- 早期試卷有些科目名稱、適用港區及考試制度與現行不同；依原卷保留，不強行統一。
- 所有題目仍須第二輪逐題文字校對，特別是早期掃描原卷的字形、數字、英文拼字、題分及公式。
