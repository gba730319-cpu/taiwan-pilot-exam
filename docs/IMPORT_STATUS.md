# 歷屆考題匯入與查核紀錄

最後更新：2026-11-05

## 題庫規則
- 主要備考港區：高雄港。
- 題庫保存所有已找到的港區原卷，不把其他港區地方科目冒充高雄港題目。
- 當地水道港灣詳情依港區區分；其他科目依官方原卷適用考區共用。
- 舊年度科目名稱依原卷保留，例如民國 89 年原卷的「實用英文」不改寫為「專業英文」。
- 年度以實際舉辦考試的官方資料為準，不因兩年一次的常態自行推定年度。
- 只匯入能追溯至考選部官方試卷或官方典藏影像的題目；原卷未取得的年度不補造題目。

- 民國 89 年（西元 2000；考試代碼 089220）：五科原卷；其中英文科名為「實用英文」。

## 來源查核提醒
- 考選部說明：92 年以前試題以官方網站歷年試題查詢及圖書館公開陳列等方式查閱；92 年以後考畢試題隔日上載。來源政策可見考選部「考畢試題查閱管道」。
- 考試院業務報告所列甲種引水人報考人數顯示民國 88 年沒有列出報考人數，而 89、90、91、92 年均有報考人數。這可作為年度舉辦與否的旁證，但是否實際開考仍以考試公告、官方試題為準。
- 民國 91 年五科原卷目前已在 sources.json 登錄 moex-091-*，不再是待查線索。
