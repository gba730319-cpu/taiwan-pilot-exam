# 離線版（PWA）說明

## 功能範圍
- 網站支援安裝至手機主畫面，以獨立視窗開啟。
- Service Worker 會預先快取首頁、完整模擬考頁、離線提示頁、網站 manifest 與應用程式圖示。
- 使用者在線瀏覽時，網站同源的頁面資源、JavaScript、CSS 與資料請求會逐步加入快取。
- 歷屆題目與參考答案整合於首頁應用程式中；首次在線載入首頁及其程式資源後，可離線瀏覽已載入的題庫內容。
- 模擬考頁面及其程式資源首次在線載入後，可離線組卷及作答。
- Google Fonts 外部字型依賴已移除，避免字型網路請求影響離線顯示。

## 首次使用
1. 使用 Safari 開啟正式網址。
2. 保持網路連線，先開啟首頁及「完整模擬考」頁面，等待兩頁載入完成。
3. iPhone：點選 Safari 分享按鈕，再選「加入主畫面」。
4. 從主畫面圖示啟動網站；完成首次快取後，可在無網路時使用已快取內容。

## 離線限制
- 首次快取前必須連網。
- 考選部原卷 PDF、外部參考資料及其他外站連結，未預先下載者離線時無法保證開啟。
- Service Worker 會快取已造訪的同源頁面及資源；新增版本需在連網時重新開啟網站，讓快取更新。
- 模擬考試卷、作答內容、計時進度與目前題號會自動保存於裝置的 localStorage；重新整理或關閉頁面後可接續作答。清除 Safari 網站資料會一併清除本機作答紀錄。

## 驗收清單
- [ ] 正式網址可載入 `/manifest.webmanifest`。
- [ ] 正式網址可載入 `/sw.js`。
- [ ] iPhone Safari 可加入主畫面。
- [ ] 首次在線開啟首頁與模擬考頁面後，無網路時仍可開啟兩頁。
- [ ] 已載入的題目、參考答案、數學公式及表格可離線顯示。
- [ ] 模擬考可離線組卷、切換題目及輸入答案。
- [ ] 模擬考重新整理後可恢復原本試卷、作答內容及計時進度。
- [ ] 外部 PDF 離線不可用的限制有清楚說明。
