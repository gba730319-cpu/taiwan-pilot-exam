# 擬答與實務解析：資料規格及品質控管

## 目的與底線

本資料層用來建立可追溯、可更新、可審查的備考內容。**擬答不是考選部公布的標準答案**；除非有官方評分標準或官方解答文件，網站不得使用「標準答案」「官方答案」等字眼。

不得只憑模型印象、單一搜尋摘要或未注明版本的網路文章，產生看似確定的法規條文、港口限制、潮汐數字、碼頭水深、拖輪能力或操船結論。資料不足時必須明確標示待查，不得補造。

## 檔案與關聯

- `data/questions.json`：唯一題目主檔。題目 ID 不變，答案以 `questionId` 外鍵連結。
- `data/answers.json`：答案紀錄；初始為空陣列。沒有完成來源查核的內容，不可先塞入正式答案。
- `data/answer.schema.json`：答案 JSON Schema，限制欄位與允許狀態。
- `docs/ANSWER_AUTHORING.md`：本文件，規範撰寫、引用、審查與更新流程。

同一題可有多個版本，但正式顯示時只取該題最新且符合展示門檻的版本。更新答案不得覆寫題目原文或題目來源資料。

## 每份答案必備欄位

1. `modelAnswer`：考場可直接書寫的擬答，依題目要求控制篇幅與結構。
2. `practicalAnalysis`：解釋背後原理、引水實務、風險與操作判斷；不得只把擬答換句話說。
3. `keyPoints`：分成 essential / supporting / bonus，指出得分核心。
4. `references`：每項重要法規、數值、港規或技術主張都要有可追溯來源，盡量記錄條文／章節／頁碼及版本日期。
5. `assumptions`、`limitations`：列明題目未提供但分析必須假設的條件，以及答案適用範圍。
6. `verification`：記錄查核狀態與具體檢查項目。不得以「已核對題目原卷」推論「擬答已核實」。

## 指定專業參考著作

使用者指定以下方信雄著作列為引水、避碰及操船題目的重要參考書目：

- 方信雄，《船舶引航專論》。優先用於引水制度、引水作業程序、引水人與船長職責、引航實務、港區引航風險及相關案例。
- 方信雄，《航行避碰與操船》。優先用於 COLREGs 規則理解、船舶操縱原理、避碰判斷、港區操船及實務案例。

使用原則：
1. 將上述著作與適用年度法規、IMO／主管機關正式文件、官方事故調查報告及港口公告交叉核對；若內容涉及法定義務或限制，仍以正式法規及公告為準。
2. 若尚未取得可查閱的書籍全文或相關頁面，只能列為指定參考書目，不得聲稱已核對書中內容，也不得虛構章節、頁碼或引文。
3. 一旦取得可查閱版本，應記錄版次、出版年、章節／頁碼及該段內容實際支持的主張；不同版次內容可能不同，引用時須註明版本。
4. 書籍觀點若與現行法規、考題年度有效法規或官方事故調查結果不一致，須說明差異並以適用的一手資料為準。

## 依科目採用的證據優先序

- 航政／行政法規：依題目內容優先查核《引水法》、《商港法》、《引水人管理規則》（及相關管理規章）、相關施行細則與子法、主管機關正式函釋及公告。涉及船舶航行、避碰責任與航行規則時，並參照《1972 年國際海上避碰規則》（COLREGs）中英文正式文本。答案須核對條文、修正沿革及生效日期；歷史考題應以考題年度有效版本作答，必要時再補充現行規定，不得混用不同年度版本。
- 當地法規與水道港灣詳情：優先查核題目指定港口的港口規章、船舶進出港管制基準、港勤作業規定、錨地及航道公告，以及臺灣港務公司／分公司和港口主管機關的正式公告、官方港圖與海氣象資料。高雄港題目優先使用高雄港相關正式規定。碼頭、航道、管制門檻及水深均需核對適用港區與資料日期；不可把舊年度港況當成今日現況。
- 引港學：除 IMO 文件及航海專業教材外，應優先參考地文航海教材、海圖圖例／海軍圖例相關正式書籍與圖表，並搭配海圖、航路指南（Sailing Directions）、燈標表（List of Lights）、潮汐表、潮流圖及航船布告等可靠資料。涉及海圖符號、航標、定位、航法、潮汐潮流、風浪與氣象、航行警告等內容時，須確認符號版本、圖例定義、資料基準及適用海域；不得只憑記憶描述圖例。
- 航海英文／專業英文：優先對照《1972 年國際海上避碰規則》（COLREGs）中英文正式版本，並參考 IMO 正式文件及公認海事術語。避碰規則名稱、條號、定義及關鍵用語應採正式中英文對應，不以一般字典直譯取代。翻譯答案以準確、自然且符合海事語境為原則。

若可靠來源彼此衝突，列出差異、日期與採用理由，不自行把衝突抹平。


## 高雄港當地港航題的官方資料庫

凡題目屬於「當地水道港灣詳情」，或其他科目實際涉及高雄港航道、碼頭、錨地、浮筒、拖船、VTS、登輪區及港區設施時，均應優先檢索臺灣港務公司高雄港務分公司官方網站，不限於某一年度或單一題目。以下頁面列為固定查核入口：

| 官方資料 | 主要用途 | 使用限制 |
|---|---|---|
| [港埠營運設施總表](https://kh.twport.com.tw/zh-TW/port/Articles?a=919) | 各碼頭編號、長度、寬度、用途、使用水深；航道及迴船池基本尺度 | 網頁現況資料不可直接代替歷史年度資料；仍須參照全港區實測水深圖 |
| [公共水域（含浮筒座標間距）及附屬港水深圖](https://kh.twport.com.tw/zh-TW/port/Articles?a=920) | 浮筒座標及間距、一／二港口外水深、全港區水深 | 註明圖資更新日期；不得把現行座標或測深無條件回推至舊年度 |
| [高雄港船舶進出港及移泊交通管制作業原則](https://kh.twport.com.tw/zh-TW/service/Articles?a=1052) | VTS進出港與移泊排班、拖船申請時機、船舶排序、港內航行注意事項 | 本頁可見107年訂定及112年修正沿革；作答須取得考試年度有效版本 |
| [高雄港錨泊使用管理規定](https://kh.twport.com.tw/zh-TW/service/Articles?a=1051) | 錨區範圍、WGS84座標、用途、錨泊申請及限制 | 現行版本與歷史版本分開處理；危險品船專用錨區不得與一般錨區混淆 |

| [高雄港歷史沿革／建設計畫](https://kh.twport.com.tw/port/Articles?a=229) | 港區擴建、洲際一期／二期工程、碼頭啟用及設施變遷 | 需辨明計畫核定、施工、完工、交付及正式營運日期，不可混為同一時間點 |
| [高雄港第七貨櫃中心計畫](https://kh.twport.com.tw/opendata/Articles?a=1043) | 洲際二期貨櫃中心工程內容、碼頭席數、深度及工程時程 | 依考題年份判斷當時是規劃、施工或營運階段 |

查核程序：
1. 先以題目所列碼頭、浮筒、港口、船渠或設施名稱，查官方設施表、港區圖及水深圖。
2. 操作程序及交通順序，查高雄港VTS排班與移泊管制原則；拖船艘數／馬力另查國際商港港勤拖船調派及管理要點及高雄港分公司附件規定。
3. 錨地與禁錨區，核對官方錨泊管理規定、海圖及航船布告；浮筒位置不可只依文字敘述推估。
4. 涉及洲際二期、碼頭新建／拆除或港區改建，應同時查工程沿革、施工公告、完工驗收及正式營運日期。
5. 每一項數值都記錄資料日期、適用區域及版本。官方現行頁面若與考試年度不同，答案須分開說明「考試年度狀態」與「現行狀態」。
6. 官方資料可用於建立港區事實，但不能取代引水人依船舶操縱性能、即時風流、潮位、UKC、交通及拖船實際配置所作的專業判斷。

## 操船情境題的必要分析順序

1. 題目已知條件與缺少條件：船型、尺度、吃水、載況、螺槳／舵型、推進器、風流潮、能見度、水深、航道寬度、泊位環境、拖輪數量／馬力／繫纜位置。
2. 主要危害：偏航／橫移、船速與舵效、淺水艉座、岸壁效應、風壓、流壓、餘裕水深、拖纜受力、失去操縱能力、交通衝突。
3. 操作目標及計畫：進路、速度控制、轉向點、拖輪任務、主機／舵／錨備便、通訊與中止條件。
4. 執行中監控：位置、航向、對地／對水速度、橫移率、風流變化、測深、拖輪回報及船橋團隊閉環通訊。
5. 風險控制與備案：安全界限、替代方案、暫停／中止／復航條件、緊急應變。
6. 限制聲明：沒有足夠船舶操縱資料時，不得假裝能給出唯一操船步驟或精確舵角、車鐘、拖輪拉力。

## 法規與港口資料的特別規則

- 法規題以備考目標考試年度（目前為預定 2027 年 6 月）可適用的現行法規作為主要擬答基準；同時標示查核日期，並在考試前重新核對修法與施行日期。只有題目明確要求解釋當年法律背景、或分析歷史法律責任時，才將考古題年度法規列為歷史補充。不得把舊法條當成考生今天應背誦的現行規定。
- 法規查核清單依題意涵蓋《引水法》、《商港法》、《引水人管理規則》及相關子法／管理規章、地方港口規定，以及《1972 年國際海上避碰規則》（COLREGs）中英文版本；並非每題都要硬塞入全部法規，只引用真正適用的規定。
- 引用法規需寫出法規全名、條次、版本／修正日期及官方來源。
- 港口限制需附公告或規定名稱、發布／更新日期、適用港區與條件。
- 數值若無可確認的官方來源，標示「待官方資料確認」，不可估算後當成事實。
- 若官方來源只有掃描影像，應以頁碼及影像人工複核，不因 OCR 文字看似合理就視為已確認。

## 品質狀態與上架門檻

- `draft`：初稿；不作為可靠擬答展示。
- `source_checked`：重要事實已附來源並完成來源內容核對。
- `technical_reviewed`：除來源核對外，已由具相關專業能力者檢查技術推理、單位、假設及操作風險。
- `approved_for_study`：完成編輯與技術審查，可作為正式備考參考內容。仍須標示非官方解答。

若無法取得可靠來源，狀態停留在 draft 或 source_checked，並列出待查項目。不可為了填滿題庫而降低門檻。

## 顯示原則

- 網站前台以使用者需求為準：題目下方只呈現「參考答案」，不另外顯示得分要點、資料來源、實務解析、評分表或查核紀錄。
- 來源、法規版本、查核狀態及技術審查資料保留於後台，作為答案品質控管依據，不增加考生閱讀負擔。
- 未完成必要查核的答案不得冒充可靠擬答上架；尚無答案時顯示「參考答案建置中」。


## 面向未來考試的年度複核原則（2026-11-07 起適用）

歷屆試題是訓練未來考試與引水實務的素材，不是要求考生複製過時答案。自本原則生效日起，所有年度答案依下列規則重新檢驗，並由最新年度往較早年度逐年推進：

1. **考生現在要學會什麼，優先於當年答案長什麼樣。** 題目原文、題號、配分與原卷年代完整保留；參考答案則以目前可確認、且面向下一次考試的知識為主。
2. **法規題採目標考試年度基準。** 目前先以預定 2027 年 6 月考試為目標，使用查核日有效且預期適用的法規；列明法規全名、條次、修正公布日及施行日。若考前再修法，必須更新。舊年度條文只放在必要的歷史背景，不可混入現行答案。
3. **港口與航道題採現況主答、歷史附註。** 高雄港碼頭、航道、迴船池、錨地、浮筒、導航設施、VTS、拖船及管制基準，優先查最新港務公司／主管機關正式資料、海圖、航船布告及實測水深圖。每個數值標示資料日期、版本、單位及適用區域；舊港況僅用來解釋原題，不得作為今日航行依據。
4. **操船與引水題以可轉移的專業能力作答。** 優先說明船舶操縱原理、風流潮、淺水與岸壁效應、UKC、拖船能力、BRM/MPX、VTS協調、風險界線及中止條件。若題目提供特定年代或特定船舶資料，須分清「題目情境條件」與「現今通用原理」，不可將單一事故或港口規定擴張成通則。
5. **英文題保留原文，補充現行專業用語。** 以 IMO、COLREGs 及公認海事術語核對；過時或不標準用語應註明，避免只因舊題使用而要求考生照抄。
6. **每題標示時間基準。** 答案應明確寫出「資料查核截至 YYYY-MM-DD」；涉及法規、港口數據或作業公告時，另列文件版本／生效日期。未來考前安排一次全題庫時效更新。
7. **雙層呈現。** 前台參考答案先呈現現行知識與可直接應考的完整作答；歷史題目背景、舊版法規／港況差異及來源查核紀錄留在補充或後台，不讓舊資料干擾考生。
8. **資料不足不猜測。** 若現況數值、法規版本、工程啟用狀態或實際作業門檻無法以可靠來源確認，明確標示「待官方資料確認」，並提供可安全作答的原理與限制；不得以歷史數字冒充現況。

年度複核順序固定為 114、112、110……逐年往前，直到正式題庫最早年度 83 年。每一年度須完成題目盤點、答案現行性、來源時效、專業推理、歷史誤導風險及缺漏標記，才進入下一年度。
